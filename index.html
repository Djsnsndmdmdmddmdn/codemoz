<bem-vindo/>

Aprende a construir a web que Moçambique ainda vai usar.

A CodeMoz é uma academia em Maputo dedicada ao ensino prático de HTML, CSS e programação de aplicações web — dos primeiros marcadores <div> até ao lançamento do teu primeiro site.

<porquê/>

Porque escolher a CodeMoz

  • Turmas pequenas, com acompanhamento próximo de cada formando.
  • Projectos reais para o portefólio, não apenas exercícios soltos.
  • Aulas em português, com exemplos e contextos moçambicanos.
  • Certificado reconhecido no final de cada módulo.
<processo/>

Como funciona a inscrição

  1. Preenche o formulário na página de Contacto.
  2. Recebe uma chamada da nossa equipa para perceber o teu nível actual.
  3. Escolhe o módulo: Fundamentos de HTML/CSS, Bases de Dados ou Java.
  4. Começa as aulas e constrói o teu primeiro site na primeira semana.
<módulos/>

O que vais aprender

Um percurso estruturado do design de interfaces à lógica de programação.

01

Web Design

HTML semântico, CSS responsivo, menus de navegação e boas práticas de acessibilidade.

02

Bases de Dados

Modelação, normalização (1FN, 2FN, 3FN) e manipulação de dados com SQL.

03

Programação Java

Orientação a objectos aplicada a sistemas de gestão reais.
